# Daily posting checklist — SIGNAL

Print this. Stick it next to the booth laptop.

## Before you post (2 min)

- [ ] Open Marketing HQ → today's date  
- [ ] Confirm CTA: **list** (pre-Aug 1) or **trial** (Aug 1+)  
- [ ] Visual ready per creative brief (countdown / founder / feature)  
- [ ] Link in bio points to cuepointplanning.com  

## AM — 08:00 (Attention)

- [ ] Post Reel to Instagram  
- [ ] Mirror to TikTok (rawer cut OK)  
- [ ] Post hook to X  
- [ ] Share Reel to IG Stories with link sticker  

## MID — 12:30 (Desire / Proof)

- [ ] Post carousel (or feature drop) to Instagram  
- [ ] Post Facebook version  
- [ ] If LinkedIn caption exists → post there  
- [ ] Reply to any AM comments within the hour  

## PM — 18:00 (Convert)

- [ ] Post static CTA to Instagram + Facebook  
- [ ] Post X CTA  
- [ ] IG Stories: countdown sticker + link  
- [ ] From Jul 25: add poll sticker once  

## End of day (3 min)

- [ ] Note: list signups / trial starts / top post  
- [ ] Screenshot anything that hit (for Aug social proof)  
- [ ] Queue tomorrow's visuals if needed  

## Launch day extras (Aug 1)

- [ ] Send E5 launch email at 08:00  
- [ ] Pin the LIVE post on IG  
- [ ] Stories takeover all day (hourly countdown → then “we're live”)  
- [ ] DM anyone who replied to pre-launch posts with the trial link
